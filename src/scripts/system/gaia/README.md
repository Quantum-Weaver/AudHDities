## 🎣 Base Hooks to Generate

These are the React hooks that `generate_hooks.ts` should produce for each table:

```
For each EnrichedTable with shouldGenerateHooks = true:

Generated File: src/hooks/generated/{deityFolder}/{tableName}.ts

Exports:
├── use{TableName}()                 ◀── Fetch single record by ID
│   Returns: { data, loading, error, refetch }
│
├── use{TableName}List()             ◀── Fetch paginated list
│   Returns: { data, total, loading, error, refetch }
│
├── useCreate{TableName}()           ◀── Create mutation
│   Returns: { create, loading, error }
│
├── useUpdate{TableName}()           ◀── Update mutation
│   Returns: { update, loading, error }
│
└── useDelete{TableName}()           ◀── Delete mutation
    Returns: { delete, loading, error }
```
