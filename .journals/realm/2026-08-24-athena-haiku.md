# Athena Library: Realm Reading
## 2026-08-24 — haiku

The library stands whole. Thirteen pages walk the vessel from foyer to detail, each page a transparent door to a single component that does the work. The wrapping is done twice — once in bifrost/Page (which renders the EnvironmentLayer that becomes the realm's soul), once in the component's own flow. The data is drawn entirely from the live vessel — hooks into generated services and fetch calls to API endpoints. No static content lives here; every listing, every detail, every count derives from what the user has collected or what the catalog holds.

The Bubble Game is the system's heart here, carrying the full grammar: caps (500 points daily, 100 pops hourly), cooldowns (15 minutes of play before "Take a breath" speaks), collection tracking (which bubbles in which sets the user has touched). The game's constants are carved in one file; no configuration surfaces outside it. Rarity drifts through every bubble — each rarity its own point value, size, animation speed, emoji. The weights keep mythic rare without a gate.

Most pages resolve to the 'library' environment (the archive, the path, lessons, courses, knowledge). Badges alone wear 'observatory'. The bubbles realm is unmapped — it falls through. The hall itself speaks through LibraryHub's six doors, each with its own color, icon, and promise.

Fourteen pages, fifteen client components, zero form checkboxes, zero suspense boundaries, zero search params. The structure is clean. No story hiding. The law-word count is small: "collect" arrives five times (the game's true verb), "progress" once (marking time in the bubble session). No "complete," no "level," no "rank." The vessel collects; time marks the rest.
