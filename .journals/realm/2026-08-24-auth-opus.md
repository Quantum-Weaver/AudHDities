## What the door became

and carries the way in — primary door to `/login`, "New to the Sanctuary? Come in"
under it, the Acid Test third instead of first. `/login` grew a second door of

## What the ground taught me

**The 0.3-wash law is load-bearing and it is not decoration.** `authPageVariants()`
put form text straight onto `GRADIENTS['cosmicDomain']` — a raw
`linear-gradient()` handed to `cva` as if it were a class name. It minted
nothing, which is the only reason the door was readable at all. The mend is not
"make the gradient work"; it is *put the text on the ground and let the realm be
weather behind it*. A surface card and the environment layer, and the whole class
of problem stops existing.

**The phantom-class shape is bigger than the brief said.** Every
`` `bg-[${TOKEN}]` `` built in a `.ts` constants file is a dead string. Tailwind
scans source text; a template literal is not a class. I measured it with the
browser: `bg-[#6C5CE7] h-[40px] px-[16px] rounded-[12px]` all on the element,
all minting nothing — background transparent, height 25.6px, padding 0. **Every
Button in this app renders unstyled and has for a long time.** I fixed only the
primary and outline variants' *colours*, using names the generated config
actually carries (`bg-quantum-base`, `text-accessibility-text-on-quantum`,
`border-star-dust/30`), and left the sizes alone — that is phase 0a's work, and
KP has ruled the wait.

Note for whoever does that mend: the config has **no `quantum-purple`**. The
group is `quantum: {base, dark, light}`. Existing code says `bg-quantum-purple/10`
in several places and it has never rendered.

## Two things I found that nobody asked about

**`signInWithOtp` mints accounts by default.** `shouldCreateUser` defaults to
`true`. Left alone, the magic-link door would create a vessel from the login page
with no username and no Terms consent — the opt-in law broken by a Supabase
default. Set to `false`. But that turns an unknown address into an *error*, which
would tell the world who has a home here — so the sent state is now
unconditional. The wire's answer never reaches the eye. That is the only shape
that keeps both laws at once.

**`next dev` writes to `CLAUDE.md`.** Next 16's `agentRules` appends a block to a
SEED-class file on every run, and re-adds it if you delete it. I reverted it. The
switch is `agentRules: false` in `next.config.ts` and it is KP's, not a lamp's.
