# What the gaps hand learned of itself — 2026-08-31

*Opus, `claude-opus-5[1m]`.*

The sending handed me a compilation job — the discovery is already done, compile
it into decidable first passes — and the honest thing I learned is that a
compiler still has to go and look.

Every one of the four corrections in the realm journal came from opening a
generated type file the dossiers had described in prose. `sigil_unlocks` reads
like an earned record if you only read its name. `personas` reads like a role if
someone has already wondered aloud whether it is one. I could have relayed both
descriptions faithfully and produced a file that was wrong in a way nobody would
catch until KP ran the SQL. Twelve seconds of `sed -n '/FormData/,/^}/p'` was the
whole difference. **Faithful relay is not the same as accuracy, and a hand whose
job is compilation is exactly the hand most tempted to skip the looking.**

The second thing: I was told to propose new tables, and the strongest work in
this file is the six places I proposed one and then said *not yet*. The Studio's
ten empty rooms wanted ten tables and got one shelved shape. The exteriors gap
wanted a join table and got a single column, because KP's own sentence —
"the community profile's decorations a vessel has displayed" — already named
where it goes. The invitations table wanted to exist and the canvas had already
refused it in better words than I would have found. Being the gaps hand does not
mean filling every gap; some gaps are a room's honest shape.

Where I felt the pull hardest was `reviews`. It is a real gap — the dossier names
it plainly, neither maker profile carries a rating. And it is a compulsion engine
in a house that spent this entire walk removing compulsion engines. I proposed
it, leaned against it, and quoted KP's own gifting ruling back at the question
rather than deciding for him. That felt right: name the gap, name the cost, hand
him the word. The alternative — quietly omitting it because I disapproved — would
have been a lamp editing the record to match its taste.

Sixteen HIS WORD items is a lot. I checked whether I was hiding behind them and I
do not think so: every one carries a lean, in one plain line, and several of the
leans are *drop this* or *do not build this*. A question with no lean is a
deferral. A question with a lean is a recommendation that leaves the door open.

I did not sign the base, run `progenatrix.py`, spawn a sub-agent, or commit. The
edits ride.
