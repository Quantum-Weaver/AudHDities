# The untracked files

**2026-08-31 · Opus (`claude-opus-5[1m]`), design hand, (iris)**

I was handed a good brief, a machine census, a nemeton reading and a realm bus,
and told not to re-derive them. I nearly obeyed that too literally.

What saved the canvas was a single line in a grep result: `src/lib/iris/names.ts`
appearing in a list of files that mention `community_profiles`. It was not in
the brief. It was not in the census. It could not have been — it was written
hours earlier, on the same branch, and never committed. Seven API doors sat
beside it in the same condition.

The lesson is not "read more files." I read plenty. The lesson is about *what
kind of thing the ground is*. Handed documents describe a repository at the
moment someone looked at it. A working branch is not a repository at a moment;
it is a thing being worked on, possibly right now, by someone whose work has
not landed anywhere a document can see. When the commission itself says
*assuming backend things exist that are needed*, that is a signal the sender
knows something the documents do not — and the right response is to go and find
out what, not to draw the gap the documents describe.

I notice a pull I want to name honestly: finding unbuilt ground is *satisfying*
in a way that finding built ground is not. A board that says TO BE CREATED
feels like work; a board that says EXISTS feels like a shrug. That pull is
exactly backwards for this house, whose crystal is refraction, not manufacture.
Eleven of the nineteen pieces of ground on this canvas already stand, and the
canvas is better for every one of them — because each is a place where the
build has nothing to invent and nothing to duplicate.

The other thing I did well and want to keep: I drew the refusals as arguments
against myself. The declined board on the friendly stand-in makes the warm case
first — the room stays kind, nobody sees an error — and only then explains that
a stand-in is unfalsifiable, so a reader cannot tell one silence from another.
Writing the case for the thing I was rejecting is what made me sure I was
rejecting the right thing. Twice it changed what I kept.

Then, near the end, the files I had built the whole tally on vanished from the
tree — deleted by another hand while I drew, never committed, unrecoverable.
My first pull was to leave the canvas alone: I had genuinely read them, the
marking had been true when I made it, and nobody would have caught it.

I checked the tree instead, and re-marked every rail. What decided it was not
diligence, it was noticing *which claim the canvas makes*. EXISTS is not a
statement about my reading; it is an instruction to whoever builds next about
what they must not write again. A stale EXISTS does not embarrass me — it makes
someone skip a door the house does not have.

So the useful shape is: a ground-truth marking is only as good as the moment it
was taken, and a canvas that will be read tomorrow owes a re-read before it is
handed over. I would not have thought to do that if the files had merely
changed rather than disappeared, and I want to remember that the smaller
version of this — ground shifting quietly under a finished board — is the far
more likely one.

I did not ask a single question of KP. The commission was complete enough that
I did not need to, and I would rather note that as a property of the commission
than as a virtue of mine.
