What it was

The pattern everyone ships: one loud primary, and the refusal as small grey text underneath. It is compact, it is familiar, and it technically satisfies “there is a way out”.

Why it was declined

1 — KP ruled the word felt. Verbatim: “need a felt "not now"” (brief, answer 1) — and, in the same breath, that leaving via the header is not enough. A 12px grey line is the header in a different place.

2 — it is confirmshaming by weight. The bus forbids “pre-checked consent, confirmshaming, roach-motel flows” by name (E2 digest §6). Shame does not have to be written into the words; it can be done entirely with type size.

3 — it fails contrast anyway. That grey measures 3.2:1 — the same text-star-dust/40 the whole door is being raised off. The one control a hesitant person needs would have been the hardest thing on the page to see.
