The pair, side by side

Same copy, same geometry, same tab order, same 48px door, same 40px fields, same 12px radii. Only the four tokens swap. If anything else moved between board ② and this one, the dress would have become a redesign.

What the swap is, exactly

deepSpace → starDust (the ground)

surface → mystical.moon (the card)

starDust → accessibility.text.onLight (the text)

neurospark and quantum.purple → quantum.dark (link, focus ring and door)

Four rows. That is the whole light theme, and it is the size the light theme should be.

The sensory ten, here

Every point is board ②’s, unchanged — the dress does not touch pace, saving, flashing, autoplay, language, next steps, the more-info door, reduced motion or the keyboard. Only contrast moves, and every figure above was re-measured against this dress rather than carried over.

One thing this board is not

It is not a request to build a theme switch. The plan’s verify step names three theme states and the ground has one; this board simply shows that the palette can carry a second dress without a new colour being invented, and what it costs when a token is asked to cross and cannot. Whether the app gets a light dress at all is KP’s, unasked and unruled.
