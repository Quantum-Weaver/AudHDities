Reduced motion, drawn proposed

The stars stop drifting and start arriving. Under prefers-reduced-motion the animation loop keeps its spawn rhythm but not its travel: a star fades in where it belongs, waits its while, and fades out. Same game, same rarities, same caps — no motion across the screen.

The pop mark stops pinging. animate-ping becomes a still glyph that fades. And hover:scale-110 active:scale-90 get the guard the rest of the house already writes.

And the card’s flip stills to a plain reveal. If the gallery takes the flip at all, it takes the app’s guard with it: the turn keeps its two faces and loses its half-second rotation — the back simply replaces the front (motion-reduce:transition-none, gallery/+page.svelte:346). Same two faces, same tap, no rotation in depth. Nothing about the game becomes unavailable under the guard.

KP ruled the guard mended; he did not rule its shape. This is the plainest shape that keeps the game a game. HANDOFF.md already holds the principle for the whole app: “motion is content, so it needs consent.”

Keyboard and touch, drawn proposed

A popped card is a button; a waiting card is not. The app draws exactly that (+page.svelte:338, :375): a collected card is a real <button> carrying aria-pressed for its turned state and a label that says what a tap will do — “Velkomin — collected. The chips are groups. Rarity and status chips sit in role="group" with a labelled heading and carry aria-pressed each (:259, :279). The Library’s chips carry neither (:136–154).

The schema lines, named — not written

Neither table has anywhere to put a colour. bubbles holds nineteen columns and none of them is palette, ring or metadata (database.types.ts:823–843); collection_sets holds fifteen and none is accent, palette or metadata (:1132–1147). There is no jsonb bag to lean on in either — the only jsonb anywhere near this is vessel_bubbles.collection_context, which belongs to the pop and not to the star. So it is new columns either way. The minimum, four lines:

bubbles  + palette text[]

bubbles  + ring text

collection_sets  + accent text

collection_sets  + palette text[]

A metadata jsonb on each would do the same work in two lines instead of four — which shape the house wants is his, not a lamp’s. Note what the columns would hold: cosmic token KEYS (hearth.gold, pride.red), not hex, exactly as the app stores them — the one raw hex in the whole set is intersex’s #7902AA, and it is raw because no token stands for it yet. A column of token keys keeps the palette a palette. And 008’s own GATE 3 says “bubble colors derive from rarity in code, never from rows” (sql/008…:31–33) — that gate was written before flags existed; a flag’s stripes cannot derive from its rarity. Whether the gate moves is his.
