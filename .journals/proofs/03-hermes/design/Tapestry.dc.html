The bodies, and the desktop law

KP ⚛, ruled 2026-08-24: one works row + one wares row per app carrying all its bodies · a file_registry row per body · APK + MSI + NSIS on the stall, the AAB for Play.

Three bodies, not a “download” button. Every figure above is read from the shelf, not invented: resonance-assets/releases-current/compass/bundle/ holds the .apk (132 MB), the -setup.exe (21 MB) and the .msi (23 MB). The version v2.3.6 is read from the bundle’s own filename, never typed.

The fourth body is withheld, and the stall never mentions it. The .aab (95 MB) sits in the same folder and is Play’s upload artifact, not a person’s download (PLAN §5, reading RELEASE-STRUCTURE.md). A stall that lists a file nobody can open is a stall telling a small lie.

Desktop is never a footnote. RELEASE-STRUCTURE.md via PLAN §5: both desktop bundles are release artifacts — “many people cannot use a phone for this”. So mobile and desktop are three equal rows in one list, same height, same weight, in the order the shelf holds them. No “also available for”.

Today the bodies are a sentence, not a list. CreationDetail.tsx:106–110 renders “Available for Android · PC” from metadata.formats (:41–49) — a display string with no file behind it. Neither wares (23 cols) nor works (17) holds a file pointer; cover_url and media_urls are display images. The frame replaces the sentence with the rows, and board ④ is where they are put there.

The price as invitation — the law it obeys

“No dark patterns. No hidden fees … Price should feel like an invitation, not a demand.”

L1-01, the verb-pair / commerce law · E2 §1, Row 5 (bus L495–499). Hence: Receive · Bring home, never Buy. The census found no “buy”, “cart” or “purchase” string anywhere in the realm — that law already holds and this board does not disturb it.

The split is on the stall, not behind the gesture. PriceBreakdown renders at the detail page before the button is ever pressed (CreationDetail.tsx:126–134) — law 7 of this realm’s bus, “a protected feature” (REALM-BUS.md:18–19). Every figure drawn above is the component’s own arithmetic at $3.33 with residual_pool_percent = 30, and it balances at two decimals: 0.33 + 3.00 = 3.33; 0.10 + 0.23 = 0.33.

The sensory ten, here

no flashing — the only motion is the loading skeleton’s animate-pulse, and drawn here the empty state replaces it rather than shimmering at it.

no autoplay — nothing plays. Cover images are images.

plain language — 25 live user-facing strings in this realm render a mojibake em-dash. See the panel below; the pricing vocabulary is where nearly all of them sit.

obvious next steps — one action per stall. The gifted stall has Receive; the priced stall has Bring home with its amount inside it, so the button never asks you to remember a number from higher up the page.

more-info door — the split, the residual note and the three bodies all stand open on the page. Nothing is behind a tooltip that is not also in the text.

reduced motion — no transform on any card here; the wash stills to nothing.
