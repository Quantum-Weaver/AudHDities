Retiring the bell settles the red-badge law

NotificationBell.tsx:93 is the only bg-red-500 in the realm — and the realm’s own README carries the law it breaks: “no red badges anywhere” (README.md:79). It never rendered, so the law was never actually broken; it was one import away from being broken. Retiring the file is the law becoming structural instead of lucky.

Nothing needs replacing. The status bar already carries unread heralds, in hearth-gold — 12.7:1 on deepSpace, a warm colour on a calm bar (StatusBar.tsx:332–341). The bell was a second, louder copy of a thing already told quietly.

And it takes a live socket with it. The bell opens a realtime postgres_changes subscription (:44–60) that pushes new heralds into view as they arrive. That is the interrupt pattern; the Call is a room you visit. Retiring it removes the only thing in this realm that could tap a vessel on the shoulder unasked.

Retiring the score does NOT retire the score

The stranded file is a copy. The original is lit. StatusBar.tsx:68 renders SovereigntyDisplay — the same “{n} / 1000”, the same filling bar, the same four milestone sentences — on every authenticated page in the app, above every board in this canvas. Its number comes from tierLight(sovereignTier) (useUser.ts:32; StatusBar.tsx:40).

This is the finding this board exists to state plainly. Deleting SovereigntyScore.tsx is correct and changes nothing a vessel sees. If ruling 4 means the score does not return, then SovereigntyDisplay is what it is about, and board ① draws that slot empty — which is also where gate ④ independently lands. Two laws arrive at the same empty space from different directions. Named here rather than assumed: KP retired a file, and only he can retire the bar.

One more root. navigation.ts:66 gates the Observatory on minSovereignty: 100 and filterNavItems (:100) still takes a sovereigntyScore. A retired number that still opens and closes doors is not retired. Named, not touched — it is another realm’s door.

The room has two names

Proposed: the ground is silent on which name wins, so the canvas takes the room’s own.

Anti-scarcity, read honestly

“2 unread” is an honest count. A queue depth, not a score: it falls when you engage, cannot be accumulated, and nobody else can see it. The opposite shape from a sigil total.

“All caught up” is not a reward. :79 states a fact and offers nothing for reaching it — no streak, no confetti, no “keep it up”. Kept verbatim.

“Mark all read” is an exit, not a chore. It appears only when there is something to clear (:81) and clears everything at once. A vessel is never asked to work through a list.

Read-on-open, not read-on-scroll. The detail marks its own herald read when opened (NotificationDetail:41–47) — the vessel’s attention is what marks it, which is the whole of “attention returned, never harvested” in one effect hook.
