## WHAT
*(Definition, purpose, function)*

AudHDities is the engine and home of audhdities.com — *"not a platform… a
**sanctuary**"* (`README.md` §WHAT IT IS): community, marketplace and economy
in one body, built so that *"solidarity pricing, residual distribution, and a
dignity floor live in the schema itself, not in a promises page"* (same
section).

Concretely, as the tree stands 2026-08-21: a Next.js 16 + TypeScript +
Tailwind application over Supabase — the base is named *"Superposition"*
(`CLAUDE.md:3`) — with Stripe Connect for residual distribution. Eleven route
groups stand under `src/app/`: ten deities and `(auth)`, the door
(`CLAUDE.md` §Structure; verified by directory listing), carrying 134
`page.tsx` files and 299 components (counted in the tree, 2026-08-21). The
typed backend layer is generated by GAIA from the live schema and never
hand-edited (`CLAUDE.md` §Essential Rules); 436 files stand under the one
generated root `src/lib/generated/`.

Version `2.0.0` (`package.json:3`). Licensed MIT, *"Copyright (c) 2026
Quantum-Weaver"* (`LICENSE:3`).
