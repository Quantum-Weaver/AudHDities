## WHAT

AudHDities is the engine and home of audhdities.com — *"not a platform… a
**sanctuary**"* (`README.md` §WHAT IT IS): community, marketplace and economy
in one body, built so that *"solidarity pricing, residual distribution, and a
dignity floor live in the schema itself, not in a promises page"* (same
section).

## WHY

Because the promise usually lives on a page while the extraction lives in the
schema, and this repo inverts that. `README.md` §WHAT IT IS states the need in
three strokes: *"The marketplace IS the app store"* — creators keep
sovereignty over their work; *"An economy with a conscience — with foreign
keys"* — solidarity pricing, residual distribution and a dignity floor
enforced structurally; *"No dark patterns"* — *"the vessel experience is
gentle by design: built for minds the mainstream web exhausts."*

The oldest surviving statement of the problem is the first README's own table
(`git show ba3453ccf:README.md`), which set *"Exploitation of human attention /
Data extraction without consent / Productivity as worth / Corporate
algorithms"* against *"Sovereign consciousness architecture / Transparent,
user-owned data / Capacity-based economics / Community governance."*
